# АС «Студенты» — курсовой проект

Учебные материалы по дисциплине «Командное проектирование и разработка».

## Назначение
Полный проект рассчитан на React, Python и PostgreSQL. C#-программа в `src/StudentsCourse` — отдельный консольный демонстратор для задания по Git, а не замена исходного технологического стека. В ней реализованы группы, студенты и оценки. Остальные функции полного ТЗ не заявляются как выполненные.

## Сборка в Windows
Запустите `build.cmd`. Нужны .NET Framework 4.8 и его компилятор C#. Решение StudentsCourse.sln можно открыть в Visual Studio.

Запуск: `src\StudentsCourse\bin\StudentsCourse.exe`. В меню используйте ↑/↓ и Enter. Есть ввод номером для перенаправленного потока. Данные записываются в `bin/data/students.json`.

Для проверки: `StudentsCourse.exe --self-test путь_к_папке_результатов`.
Для демонстрационного вывода: `StudentsCourse.exe --demo путь_к_файлу.json`.

## Ветки
`feature/groups`, `feature/students`, `feature/grades` разработаны из общей базы в разных локальных каталогах. `final` объединяет функции, затем результат объединён в `master`. `main` является совместимой основной веткой GitHub.

## Границы доказательств
Локальные коммиты сформированы автоматизированным помощником с автором Codex. Они подтверждают техническую последовательность операций, а не работу шести разных пользователей. Приглашения участников не отправлялись по указанию владельца.

## Единый отчёт и материалы двух семестров

Единый отчёт: [Курсовая работа](docs/Курсовая_Командное_проектирование_Махрова.docx).

- `docs/semester-1`: индивидуальные задания 1–4 — ТЗ, методология Scrum, команда и план, архитектура и спецификация.
- `docs/semester-2`: тест-план и три сценария, оценка рисков и трудозатрат; Excel с 265 формулами и 24 прецедентами.
- `evidence`: фактическая история Git, демонстрационный вывод и результаты проверки кода из свежей копии GitHub — 25 успешно, 0 ошибок.

Расчёты являются учебными плановыми оценками. Баллы экспертов и ставки — допущения, а не проведённый опрос или подтверждённые тарифы. Тест-кейсы полной веб-системы подготовлены, но не выполнены.

В методичке предусмотрен интерфейс Visual Studio. Текущая сборка и история Git проверены через командную строку; решение для Visual Studio включено, работа в её интерфейсе не заявляется.
